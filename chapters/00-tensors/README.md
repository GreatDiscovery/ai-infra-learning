# 00 · Tensor 与一次学习

本章只回答两个问题：数据如何表示？模型参数如何改变？不需要 GPU，也不下载数据。

```bash
python run.py 00
```

## 先看形状

Tensor 可以先理解成带形状和数据类型的多维数组。`[2, 3]` 在本例中是 2 个样本，每个有 3 个数值特征；`[3, 2]` 的权重把这 3 个特征变成 2 个输出。矩阵乘法 `[2, 3] @ [3, 2]` 得到 `[2, 2]`。

batch 是一次共同处理的一组样本。它不是模型层，也不表示训练了多少轮。

## 再看一次学习

我们构造 `输入=[1,2,3]`、`目标=[2,4,6]`，只学习一个参数 `w`，模型为 `预测=w×输入`。正确关系是 `w=2`。

程序从 `w=0` 开始：

1. 用当前参数算预测，这叫前向计算。
2. 用预测与目标的均方误差表示错得多严重，这叫 loss。
3. `loss.backward()` 计算梯度，表示参数微小变化对 loss 的影响。
4. 执行 `参数 -= 学习率 × 梯度`，再检查 loss 是否下降。

默认输出应约为：参数从 0 变为 1.867，误差从 18.667 降到 0.083。这里的负梯度表示当前增加参数有助于减小误差，不能据此认为增加得越多越好。

## 动手练习

1. 不改代码，用纸笔计算 `x @ w` 的左上角元素，核对输出。
2. 把学习率从 `0.1` 改为 `1.0`，预测误差，再运行。出现断言失败是这个练习的预期可能结果，检查输出并解释步长过大的影响，然后恢复。
3. 把目标改成 `[3,6,9]`，先判断理想参数应该是多少。

## 面试练习

先用自己的话回答，再展开参考。

<details><summary>Tensor 的 shape 与 dtype 分别表示什么？</summary>

shape 描述各维长度；dtype 描述每个元素的数据类型，例如 float32。相同 shape 的 Tensor 可以有不同 dtype。
</details>

<details><summary>backward() 会直接更新模型参数吗？</summary>

不会。它计算并累积梯度；本章手动更新参数，下一章用 optimizer.step() 更新。
</details>

<details><summary>学习率越大，学习越快吗？</summary>

更大的步长可能减少更新次数，也可能跨过较好的区域导致误差增大或发散，须结合实际 loss 判断。
</details>
