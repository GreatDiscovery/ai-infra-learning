# 02 · 学会读训练结果

先完成第 01 章，能指出前向、loss、backward 与 step。今天的目标是解释数字，而不是追求更高准确率。

## 先运行

```bash
python run.py 02
```

默认使用 CPU、1024 个训练样本、512 个验证样本、5 轮，分别尝试 Adam 学习率 `0.00001 / 0.001 / 0.1`。复用第 01 章的公开数据，首次运行可能下载；不需要预先训练模型。

每种学习率都从相同权重开始，使用相同数据划分、每轮相同样本顺序和 batch=64。`epoch=0` 是训练前的基线；每一轮结束后，用当时同一份参数重新评估训练集和验证集。这样两组 loss 可以直接对照，比把整轮训练过程中不断变化的 loss 平均值当作最终表现更清楚。

输出在 `results/02-training-results/时间戳/`：`report.md` 有完整表格和阅读提示，`results.json` 保留参数与每轮结果。不会覆盖第 01 章的模型。

## 先猜三个问题

1. 最大学习率一定收敛最快吗？
2. 准确率不变时，loss 是否也不变？
3. 训练 loss 降低时，验证 loss 是否必然降低？

准确率只看最高分的类别是否正确，交叉熵 loss 还关心模型给真实类别的相对分数。预测类别不变时，分数变化仍可使 loss 改变。学习率过小可能进展缓慢，过大可能不稳定，但没有“所有任务最优”的固定值。

## 再做一个故障实验

```bash
python run.py 02 --train-size 128 --epochs 40 --lrs 0.001 --random-labels
```

这个开关故意把训练标签替换为固定随机类别；验证标签仍是真实类别。它模拟没有有效可学对应关系的训练集，检查模型能否记住这些样本。看训练准确率能否持续提高，而验证表现是否仍差；不保证在固定轮数下完全记住。

随机标签实验帮助区分“拟合训练样本”和“对新样本有效”，不等于真实项目过拟合的所有原因。正常标签下，训练表现持续改善而验证表现持续变差也是过拟合线索；一次小幅波动不足以下结论。

其他可选命令：

```bash
python run.py 02 --epochs 10 --lrs 0.001
python run.py 02 --device mps --epochs 3 --lrs 0.001
```

## 面试问答

<details><summary>训练集、验证集、测试集各做什么？</summary>

训练集用于更新参数；验证集用于比较设置；测试集留作最终评估。本例复用官方训练集内互不重叠的训练/验证划分，没有用官方测试集挑学习率。
</details>

<details><summary>验证集上选出了最好的学习率，能把它的准确率作为最终效果吗？</summary>

反复根据验证集选参数会对它产生选择偏差，最终仍应使用未参与调参的测试集评估。
</details>

<details><summary>训练 loss 很低，验证 loss 很高，先检查什么？</summary>

检查数据划分与标签、训练/验证预处理是否一致、样本分布是否不同，再考虑模型记忆、容量和正则化。仅凭两个数字不能确定唯一原因。
</details>
